# EduForge AI

**Smart Education Intelligence Platform**

EduForge AI is a modular education intelligence platform designed to support **students, faculty, institutions and education decision-makers** through career, skill, curriculum and learning insights.

## Current Frontend Modules

- Student Intelligence
- Skill Intelligence
- Curriculum Intelligence
- Faculty Intelligence
- Education Intelligence
- My EduForge: Profile, Progress & Insights, Activity Center and Preferences

## Smart Platform Features

- Centralized learner profile for personalization
- Progress and improvement tracking
- Activity history for analysis workflows
- Role-aware preferences for different education stakeholders
- Resume and syllabus analysis workflows
- Career, skill and curriculum intelligence
- Frontend-ready architecture for backend, database and ML integration

## Technology

- React 18
- Vite
- React Router
- JavaScript
- CSS

## Prototype Data

The current frontend uses local/mock analysis data. Profile, preference and last-activity information is stored in browser localStorage so the new platform features are demonstrable before database integration.

## Planned Full-Stack Architecture

```text
React Frontend
      ↓
Backend REST API
      ↓
Database
      ↓
ML / AI Services
      ↓
Predictions, recommendations and analytics
```
